♻️ 프로젝트 명 : AI 기반 스마트 분리배출 시스템
AI 비전 모델을 활용해 재활용품의 재질 및 오염도를 인식하고, 자동으로 분리 기능 여부를 판별하여 편리하게 분리수거를 도와주는 시스템이다.
최종 목표는 정확한 분리배출로 재활용률을 높이고, 오염도에 따른 분리수거 알림 시스템을 구현하는 것이다.

📘유즈케이스 시나리오 작성
1. 사용자가 HMI 화면에서 터치를 한 후 분리수거 시작을 진행한다.
2. 물건을 넣으면 카메라가 인식해서 오염도, 라벨 유무, 분리수거 종류에 따라 분석한다.
3. 분석한 값에 따라 자동으로 분리수거가 되며, HMI에 성공적으로 분리수거가 되었는지 확인 할 수 있다.
